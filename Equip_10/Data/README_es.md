# Datos

Datasets utilizados a lo largo del proyecto, organizados por sprint.

- **Primera recepción de datos** — los datos se guardan tal cual se reciben, en
  **formato CSV**.
- **Tras la limpieza** — una vez aplicadas las transformaciones pertinentes, los
  datos se vuelven a guardar, manteniendo un **respaldo en todo momento** del
  pipeline.

| Carpeta | Contenido |
|---|---|
| `Sprint_1/` | Dataset inicial de alojamiento turístico (`df_tourist.csv`) |
| `Sprint_2/` | Dataset actualizado tras la entrega en CSV (hándicap de caída del servidor SQL) |
| `Sprint_3/` | Datasets de trabajo para los KPIs |
| `Sprint_4/` | Datasets externos del **INE** (viajeros, pernoctaciones, residencia) para el benchmarking |
