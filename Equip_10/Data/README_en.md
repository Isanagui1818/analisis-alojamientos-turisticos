# Data

Datasets used throughout the project, organised by sprint.

- **First data reception** — the data is stored as received, in **CSV format**.
- **After cleaning** — once the relevant transformations are applied, the data is
  saved again, keeping a **backup at every stage** of the pipeline.

| Folder | Contents |
|---|---|
| `Sprint_1/` | Initial tourist accommodation dataset (`df_tourist.csv`) |
| `Sprint_2/` | Dataset updated after the CSV delivery (SQL server outage handicap) |
| `Sprint_3/` | KPI working datasets |
| `Sprint_4/` | External **INE** datasets (travellers, overnight stays, residence) for benchmarking |
